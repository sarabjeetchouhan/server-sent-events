What are Server-Sent Events?

Server-Sent Events (SSE) are a browser-supported way for a server to send data to a client over a long-lived HTTP connection. SSE is unidirectional: the browser opens the connection and the server streams events. The browser's native EventSource API handles event dispatch and automatic reconnection.

SSE is useful for notifications, dashboards, progress indicators, streaming responses, and real-time order tracking. Use WebSockets instead when the client and server both need to send frequent messages over the same connection.

Spring Boot SSE endpoint

This project uses Spring MVC's SseEmitter to keep an HTTP response open and send events. Run the backend, then try the stream with curl: 

curl -N -H 'Accept: text/event-stream' \
  http://localhost:8080/api/stream

The endpoint sends ten named notification events with incrementing IDs and JSON payloads. The order example uses a separate named order-update event for each order subscription.
